# Kalkulator Interaktif

Program kalkulator berbasis menu di terminal.

## Cara Menjalankan

    python3 kalkulator.py

## Panduan Penggunaan

Setelah program dijalankan, menu utama akan tampil:

    === KALKULATOR ===
    1. Tambah
    2. Kurang
    3. Kali
    4. Bagi
    5. Riwayat
    0. Keluar

Langkah penggunaan:

1. Ketik nomor menu (1-4), lalu tekan Enter.
2. Masukkan dua angka sesuai permintaan program. Input selain angka akan ditolak dan diminta ulang.
3. Hasil perhitungan langsung ditampilkan, contohnya `8.0 + 2.0 = 10.0`.
4. Pilih menu 5 untuk melihat riwayat perhitungan selama program berjalan.
5. Pilih menu 0 untuk keluar.
